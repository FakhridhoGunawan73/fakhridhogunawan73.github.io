Overview

About the Project

RevoShop is an e-commerce web application built with Next.js 15 that displays product data from an external API through a product catalog and detail pages.

The application allows users to browse products, view product details, and navigate between pages with a responsive interface.

The project also includes a FAQ page generated using Static Site Generation (SSG), simple cart state, and contextual navigation.

The project demonstrates frontend development with Next.js App Router, TypeScript, Tailwind CSS, and Axios for external API integration.

Development

Development Highlights

Technical challenges encountered during the development and deployment process.

01. Product Catalog & Protected Routes

Integrating external product data required handling API responses and presenting the information consistently across the catalog and detail pages.

Solution

Used Axios to request data from the Platzi Fake Store API and rendered product information in reusable components.

02. Cart State

The cart interface needed simple state management while keeping the layout and navigation consistent.

Solution

Applied Dynamic Routing for product details and Static Site Generation (SSG) for the FAQ page.

03. UI & Navigation

The interface required consistent layout alignment and navigation that responds to the current page.

Solution

Configured API requests with Axios and deployed the Next.js application to Vercel.
