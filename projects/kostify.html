Overview

About the Project

Kostify is a full-stack web application developed to simplify the process of discovering boarding houses, managing rooms, and handling booking requests between tenants and property owners.

The application provides a centralized platform where users can browse boarding house listings, search for suitable accommodations, and submit booking requests.

Property owners can manage their boarding houses, rooms, and booking requests through dedicated management features.

The project was built to demonstrate the implementation of frontend development, backend development, database integration, authentication, authorization, and application deployment.

Problem & Solution

What Problem Does Kostify Solve?

THE PROBLEM

Boarding House Discovery and Management

  • • Finding suitable boarding houses can require users to browse information from multiple sources.
  • • Property owners need a convenient way to manage boarding house and room information.
  • • Booking requests need to be organized so tenants and owners can track their status.
THE SOLUTION

A Centralized Booking Platform

  • • Provide boarding house listings and search functionality in one application.
  • • Provide property and room management functionality for owners.
  • • Provide booking workflows with status tracking and approval or rejection.

Database

Database Design

The database uses relational data modeling to connect users, boarding houses, rooms, and booking records.

User

Stores user information and role data. A user can own multiple boarding houses and create booking records.

Kos

Stores boarding house information. Each boarding house belongs to an owner and can contain multiple rooms.

Room

Stores room information and belongs to a boarding house.

Booking

Stores booking requests, associated users, rooms, and booking status information.

Development

Challenges & Solutions

Technical challenges encountered during the development and deployment process.

01. Authentication & Protected Routes

Implementing authentication required coordinating JWT cookies between the frontend and backend, while protecting pages and API endpoints based on user roles.

Solution

Implemented JWT authentication using httpOnly cookies, JwtGuard, RoleGuard, and frontend route protection.

02. Booking Management

Booking functionality required managing relationships between users and rooms, preventing duplicate booking requests, and maintaining booking statuses.

Solution

Implemented booking validation, Prisma relations, booking status enums, and owner approval or rejection workflows.

03. Deployment & Integration

Deploying the frontend and backend separately required configuring environment variables, API communication, and cross-origin requests.

Solution

Configured frontend API environment variables, backend CORS settings, and separate deployments using Vercel and Railway.
